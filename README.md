# Neural-Network

```bash
#change directory to Neural Network
cd NeuralNetwork
```
<h2>Build and Run</h2>

```bash
#Make directory with name build
mkdir build

#Move to build directory
cd build

#Initialize CMake
cmake ..

#Build the Project
cmake --build .

#Run executable
./debug/NeuralNetwork.exe
```
